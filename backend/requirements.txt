# --- AI Knowledge Platform (T004) -------------------------------------------
# The default embedding provider is BAAI/bge-m3 run locally through onnxruntime — deliberately NOT
# torch, which would add ~2.5 GB for a model we only ever run forward on CPU. `fastembed` is the
# lightest way to pull the trio the provider needs (onnxruntime, tokenizers, huggingface-hub) as one
# tested, mutually-compatible set; the platform drives the ONNX graph itself because fastembed does
# not expose bge-m3 in any of its model classes.
#
# First use downloads ~2.3 GB of ONNX weights to the HuggingFace cache. Where that is unavailable
# (CI, an air-gapped host), the platform falls back to the deterministic provider — see
# AI_EMBEDDING_FALLBACK_TO_DETERMINISTIC. Retrieval then still functions but has NO semantic
# similarity, which is reported through the API's `isSemantic` metadata.
fastembed>=0.8.0
