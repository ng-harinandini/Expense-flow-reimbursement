# Skill — Handoff

**Goal:** Leave the repository in a state where anyone can resume with zero external
context.

## Procedure

1. Rewrite `HANDOFF.md` to reflect current reality:
   - Current state, active task, branch, baseline/verify status.
   - What shipped this session.
   - **Next Action** (the single most important next step).
   - Blockers / open questions.
   - Ready-for-Review checklist.
2. Ensure `LOG.md`, `TASKS/task.md`, `DECISIONS/`, and docs are all current.
3. Confirm the Execution Order can be re-entered from files alone.

## Self-Test

Ask: "If I lost all memory right now, could I resume purely from the repo files?"
If not, the handoff is incomplete.

## Output

An accurate `HANDOFF.md` and a consistent, file-backed project state.
